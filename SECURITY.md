# Security Policy

GesSnap is closed-source macOS software. We take security and user privacy seriously.

## Reporting a Vulnerability

Please **do not** disclose security vulnerabilities or privacy issues in public GitHub Issues.

Instead, send a private report to [support@gessnap.com](mailto:support@gessnap.com) with:

- The affected GesSnap version and build number (e.g. `0.1.0 (52)`)
- Your macOS version and Mac architecture (`Apple Silicon` / `Intel`)
- Clear steps to reproduce the issue and any relevant details

For information on how GesSnap handles macOS permissions and local data, see our [Privacy Policy](https://gessnap.com/en/privacy/).
