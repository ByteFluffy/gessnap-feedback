## 3. FAQ

### Can I switch Macs without losing activations?
Yes. A single Pro license supports up to **5 personal Macs**, with self-service device deactivation inside GesSnap Settings.

### Does GesSnap require disabling SIP?
No. GesSnap uses only macOS standard Accessibility permission to position windows locally and never uploads window titles or gesture paths.
