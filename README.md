## 提交反馈前请先确认 / Before Opening an Issue

1. **先搜索现有 Issue / Search first**：请先搜索是否有相似问题或建议，尽量在原 Issue 下补充你的复现场景或点赞（👍）。
2. **一件事一个 Issue / One topic per issue**：请不要在一个 Issue 中混合提交多个不相关的 Bug 或需求，方便追踪与回复。
3. **补充基础环境信息 / Include environment details**：
   - GesSnap 版本与 Build 号（例如 `0.1.0 (50)`，可在菜单栏设置侧栏底部或应用信息中查看）
   - macOS 版本与机型芯片（Apple Silicon M 系列 / Intel）
   - 辅助功能权限是否已授权、是否为多显示器 / 刘海屏环境
   - 如果涉及窗口或手势触发异常，附带截图或短录屏会极大加快排查
